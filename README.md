# SoraKanji — Capacitor native app

Native wrapper (iOS/Android) around the SoraKanji mobile web app
(`www/index.html`, synced from the live build in `donghung94/beta2.0`).

Why native: the paste-a-link shadowing feature fetches YouTube captions
**on the learner's own phone** via `CapacitorHttp` (native networking, no
CORS, residential IP). Safari/PWA and Google Cloud servers cannot do this —
YouTube blocks datacenter IPs. See `BUILD-NOTES.md`.

## iOS build (free, unsigned)

Push to `main` triggers `.github/workflows/build-ios.yml` on GitHub Actions
(free for public repos): `npm ci` → `npx cap sync ios` → unsigned
`xcodebuild archive` (`CODE_SIGNING_ALLOWED=NO`) → `App-unsigned.ipa`,
published as a release asset. Sideload it with
[AltStore](https://altstore.io) using a free Apple ID (no $99 Developer
Program needed for testing; the app expires after 7 days and AltStore
refreshes it automatically).

Notes:

- The 4 asset-catalog PNGs (app icon + splash) are binary and are **not**
  stored in this repo; the workflow generates solid-red placeholders at
  build time. Replace with real artwork before any store submission.
- `ios/App/App/public/` is generated by `cap sync` from `www/` and is not
  committed.
- Bundle id: `com.sorakanji.app`. Web dir: `www`.
